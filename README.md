# Смена — рабочий экран кабинета

Концепция переработанного первого экрана кабинета (Salebot / Mavibot).

- `index.html` — разбор и защита: что не так сегодня, что стало, до/после, критерии, риски.
- `screen.html` — **рабочий прототип экрана**. Нажимается всё; экран работает и без участия
  пользователя (выручка растёт, события приходят сами).
- `img/` — кадр «до», превью экрана для узких экранов, постер «Поделиться сменой».

Данные в прототипе взяты с реального нагруженного аккаунта: сто просроченных задач,
девять потерянных клиентов, десять зависших сделок.

Материал рабочий, к публикации не предназначен: страница закрыта от индексации
(`noindex, nofollow`).
