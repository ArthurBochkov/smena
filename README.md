# Смена — кабинет вокруг ИИ-сотрудника

Концепция первого экрана кабинета (Salebot / Mavibot). Предложение из четырёх частей:
ассистент действует вместо пересказа проблем; экран становится его сменой, а не чек-листом;
чат перестаёт быть колонкой сбоку; и всё это — в облике, который хочется переслать.
«Смена» — название экрана, а не всего предложения.

- `index.html` — предложение и защита: что предлагаем → живой экран → почему именно так →
  до/после → что такое смена → как устроено → виральность → разные бизнесы → риски → что дальше.
- `screen.html` — **рабочий прототип**, проект «Онлайн-школа». Нажимается всё; экран работает
  и без участия пользователя.
- `shop.html` — второй проект того же клиента, «Лавка». Тот же скелет, другое наполнение;
  переключатель проектов в шапке.
- `img/` — кадр «до», превью экранов для узких экранов, постер «Поделиться сменой».

Данные в прототипах взяты с реального нагруженного аккаунта: сто просроченных задач,
девять потерянных клиентов, десять зависших сделок.

Материал рабочий, к публикации не предназначен: страница закрыта от индексации
(`noindex, nofollow`).
