# Смена — концепция первого экрана

Концепт-презентация переработанного первого экрана кабинета (Salebot / Mavibot).
Одна самодостаточная страница: `index.html`. Экраны внутри — живые копии макетов,
а не скриншоты; экран «Смена — рабочий экран» кликабельный.

Материал рабочий, к публикации не предназначен: страница закрыта от индексации.
